PC&amp;移动端访问pixiv方式

pixiv，一个由日本程序员创建的以插图、漫画和小说、艺术为中心的社交网络服务里的虚拟社区网站。以其高质量的作品和涩涩（划掉）众多人气画师而出名。在中国的的各个泛二次元社交媒体上有一定的影响力。

然而在2017年前后，pixiv突然被墙，中国大陆地区的用户均无法直接访问到pixiv，其DNS解析结果为被中国大陆DNS缓存投毒过的专用IP，随后站方通过官方微博表示，“正在调查中国地区无法访问pixiv的原因。”其后网站并未恢复，但官方微博仍继续保持更新。

 现如今，国内仍然无法正常访问pixiv，上面的一些高质量的插画和漫画随之埋没。本文介绍PC端几种直接或间接访问pixiv的非VPN途径。

PC端

浏览器访问

镜像站

1. https://pixivic.com

收录较全面，基本功能均有。 

2. https://pixiviz.xyz

收录全面，基本功能均有，有特色主页。

3. https://www.vilipix.com

收录略全面，基本功能均有，排版最接近原站。

4. https://pixivel.moe/

收录最为全面，基本功能最全，有颇具艺术感的特色主页，且可以根据pid来搜索画师以及作品。 

直接访问

Watt Toolkit（原名Steam++)是一个集网络加速、库存管理、本地挂卡为一体的多功能Steam工具箱，软件除了能host加速Steam外，还能加速其他如Github,Twitch,Google验证码等。（新版本已经删除pixiv），因此，我们需要下载旧版本：Release 1.1.4 · BeyondDimension/SteamTools · GitHub。

安装完成后点击左侧的“社区服务”，在“支持的代理服务”一栏内下滑，将“Pixiv”及“Pixiv”图片勾选，点击启动加速即可。

完成后，访问pixiv官网：插画交流网站[pixiv]，耐心等待10-30秒加载，即可成功。

第三方客户端访问

采用的软件名称为Pixeval，是一个漂亮的Pixiv第三方桌面程序。

下载前，请检查是否安装.NET8.0，下载地址：.NET 8.0 Desktop Runtime (v8.0.8) - Windows x64 Installer。 

 Pixeval下载地址：Release Pixeval 4.2.2 · Pixeval/Pixeval · GitHub，可以直接在Microsoft商店下载，也可以下载你的系统架构对应的misx文件，完成后双击即可。

 打开后，会显示如上界面，选择合适的登录方式登录即可。完成后即可成功进入软件主界面。

移动端

第三方客户端

PixEz

一个简单且美观的应用，同样支持中国大陆地区直连。且访问速度还算不错。支持IOS（仅能外区ID下载）及安卓端，且完全免费。

下载链接：https://github.com/Notsfsssf/pixez-flutter

Pix助手

功能最全的移动客户端，页面简洁且支持IOS端国区和安卓，分免费版和付费版两个选择，支持大陆直连。

官网https://www.pivlite.com/

官方微博：https://weibo.com/2975751864?refer_flag=1001030103_
